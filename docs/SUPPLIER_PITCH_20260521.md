## 一页纸 2：意大利菜系食材推荐 demo（手机演示流程）

**Step 1 — 打开 nothinkeats.com**
- 进 Home → 切到 "西餐" tab → 看到 AI 推荐意大利菜单
  - 例：周一 意式番茄牛肉酱意面 / 周三 帕马森奶酪烩饭 / 周五 普切塔小食

**Step 2 — 点开任一道菜（如"意式番茄牛肉酱意面"）**
- 看到食材清单 6 项：
  - 意大利手工面（推荐 De Cecco / Barilla）
  - 罐装意大利番茄（推荐 Mutti）
  - 帕马森奶酪 24 个月（推荐 Parmigiano Reggiano DOP）
  - 特级初榨橄榄油（推荐 Frantoio Bonamini）
  - 大蒜 / 罗勒（本地超市）
  - 牛肉碎 200g（本地肉档）

**Step 3 — "一键加入采购清单"**
- 6 项食材自动汇总到本周采购页 /verify
- 雇主分享给菲佣（QR / WhatsApp）→ 菲佣按清单去买

**Step 4 — "改用供应商一键下单" (合作落地后新功能)**
- 进 /verify → 看到"由 <供应商> 直供"标签的 4 个意大利原料
- 点"一键下单" → 跳转供应商落地页 / WhatsApp 商店
- 配送到家

**关键 metric**：从打开 app 到下单完成，**3 步搞定**。

## 一页纸 3：1 个月 MVP 试运营条款清单

**核心条款**

1. **SKU 范围**：先 3-5 个高频意大利食材
   - 24 个月帕马森奶酪 100g 块
   - 特级初榨橄榄油 500ml
   - De Cecco 意面 500g（spaghetti / penne）
   - Mutti 罐装番茄 400g
   - Prosciutto di Parma 100g 切片

2. **试运营时长**：1 个月（2026-05-21 → 2026-06-21）

3. **客户引流方式**：
   - Aieats 推荐意大利菜时，菜品卡 "材料" 区显示"由 <供应商品牌> 直供"
   - 用户点采购清单 → 跳转供应商落地页 / WhatsApp 群下单
   - **不要求**做技术 API 对接（试运营简单优先）

4. **数据共享条款**（你方筹码）：
   - 供应商每周给 Aieats 提供：订单数 / 客单价 / 复购率 / 用户反馈
   - Aieats 每周给供应商：意大利菜推荐次数 / 用户画像聚合（不含 PII）

5. **商业条款**（你方建议）：
   - **方案 A 推荐**：导流 commission % — Aieats 收 8-10% / 订单
   - 方案 B：固定月费 — 对方付 HK$X K / 月不分成
   - 方案 C：纯流量交换 — 对方愿意送 N 份样品给 β 用户做反馈
   - **MVP 阶段建议方案 C** — 减少财务摩擦，先看效果

6. **红线**（你方坚持）：
   - **不允许独家排他** — Aieats 保留接其他供应商（HKTVmall / 京东 / 大昌行等）的空间
   - **不允许对方用 Aieats 用户 PII 做单独 marketing** — 用户隐私不可侵
   - **试运营失败可单方面退出** — 1 个月后 Aieats 评估 ROI，可不续约

7. **下一步**：
   - 试运营 1 个月成功 → 谈正式 1 年合同 + 扩 SKU
   - 失败 → 各回各家，无违约金

## 谈判技巧 cheat sheet

1. **开场不要先开价** — 先听对方 "你们想从 Aieats 拿什么"
2. **小批量先试** — 3-5 个 SKU 试 1 个月，对方决策门槛低
3. **demo 视频准备** — 手机打开 Aieats 现场演示意大利菜推荐 + 采购清单
4. **数据回流是核心筹码** — 强调"你们看不到的 C 端真实采购数据，Aieats 给你"
5. **如果对方要独家** — 礼貌拒绝，理由"Aieats 用户需要选择权"
6. **如果对方报高 commission** — 反提"我们承担引流成本（app 推广），合理 8-10%"
