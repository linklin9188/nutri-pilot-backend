```

/OAUTH_SETUP.md           # 已存在 · OAuth 接入清单
/docs/
├── SESSION-YYYY-MM-DD.md # 单次 session digest（今天这份）
├── ALGORITHM.md          # scoreDish 五轴 + 偏向 + ALGO_VERSION 历史

├── WECHAT.md             # OAuth + bouncer + 小程序 整合

```
