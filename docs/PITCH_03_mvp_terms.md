# 一页纸 3 — 1 个月 MVP 试运营条款清单（Term Sheet）

## 第 2 条 — 试运营时长

**1 个月**（2026-05-21 → 2026-06-21）

中间不签长约。1 个月后双方各自评估是否续约。

---

## 第 3 条 — 客户引流方式

**Aieats 端**：
- 推荐意大利菜时，菜品材料区显示「由 [供应商品牌] 直供」tag
- 采购清单页 /verify 对应食材旁加"一键下单"按钮
- 按钮跳转目标：双方约定（WhatsApp / 供应商落地页 / 实体店）

**对方端**：
- 落地页 / WhatsApp 商店 / 实体店收到 Aieats 来的客户
- 在订单备注里标记"来源 Aieats β"以便追踪

**v1 阶段不要求 API 对接** — 简单优先，1 月后效果好再谈技术集成。

---

## 第 4 条 — 数据共享条款

**对方 → Aieats（每周）**：
- 来自 Aieats 引流的订单数
- 客单价（聚合，不含 PII）
- 复购率
- 用户反馈（差评 / 投诉）

**Aieats → 对方（每周）**：
- 意大利菜推荐总次数
- 用户画像聚合（年龄段 / 区位 / 家庭结构，不含 PII）
- 算法热推菜品 top 10

**两边都不分享用户 PII**（姓名 / 电话 / 邮箱 / 地址等）。

---

## 第 5 条 — 商业条款（3 个方案，建议选 C）

### 方案 A — 导流 commission
- Aieats 收 **8-10% / 订单**
- 对方按月结算给 Aieats

### 方案 B — 固定月费
- 对方付 Aieats **HK$8K - 20K / 月**（视品牌曝光强度而定）
- 不分成

### 方案 C — 流量交换（**MVP 阶段推荐**）⭐
- 对方**送 50-100 份样品**给 β 用户做反馈
- Aieats **不收 commission，不收月费**
- 1 个月数据双方共享
- 1 月后看效果，再谈正式分成

**MVP 建议方案 C** — 减少财务摩擦，先看效果，决策门槛最低。

---

## 第 6 条 — 法律红线（双方各自坚持）

### Aieats 不让步：
1. **不允许独家排他** — 1 月内 Aieats 保留接其他供应商（HKTVmall / 京东 / 大昌行等）的空间
2. **不允许对方用 Aieats 用户 PII 做单独 marketing**
3. **不允许对方在订单页面增加"必须先关注 / 入会"门槛** — 用户直接下单不绕弯
4. **不允许"假折扣"** — 显示原价必须是真实市场价

### 对方可坚持的：
- 物流不到 4 小时不退款（生鲜冷链合理）
- 节日 / 旺季供货优先级（双方提前预案）

---

## 第 7 条 — 退出机制

**任意一方都可在 1 月期内随时退出**，无违约金。

退出时：
- 提前 3 天书面通知（邮件 / 微信均可）
- Aieats 移除对方 tag 和"一键下单"按钮
- 双方各自归档历史数据

---

## 第 8 条 — 续约条件（1 月后）

如双方愿意续约，1 月底前签**正式 1 年合同**包含：
- 扩 SKU（10-20 个）
- 切到方案 A 或 B（不再 C 流量交换）
- API 技术对接
- 营销联名活动（节庆礼盒 / 双 11）
