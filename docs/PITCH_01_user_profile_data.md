# 一页纸 1 — Aieats 用户画像 + 月数据估算

> 用途：明天供应商谈判 — 第一份呈交给对方
> 风格：诚实 + 给假设 + forward-looking 数字含 ranges

---

## 1. 目标用户群（精准 — 不是泛流量）

**核心画像**
- 香港**双职工夫妻** + 1-2 个学龄孩子（5-12 岁居多）
- 雇佣 1 个**菲佣 / 印佣**，做饭主力是她
- 家庭月收入 **HK$60K - 150K**（中产）
- 住港岛 / 九龙
- 偏大陆背景 / 已香港化（HKD 计价，普通话简体 UI）

**他们的痛点**（Aieats 飞轮数据已验证）
1. 周日晚上算下周吃什么 + 列采购清单 ≈ 1 小时心智负担
2. 菲佣听不懂中文菜谱
3. 孩子营养偏食 + 大人减脂 / 增肌 / 长辈进补
4. 采购重复浪费
5. 节庆 / 长辈来访 突然要做 8 个菜不知从哪起

**他们的付费动机**（不是为了"AI 营养专家"）
解放每周"想菜单 + 列采购"那 1 小时心智 — 用 HK$199 买回时间 + 决策疲劳。

## 3. 关键假设 + 风险（诚实告知）

**假设**
- β 引流：5-10 个朋友圈 + 妈妈群 + 菲佣中介散发
- 转化率 5%（中位，真实可能 3-10%，要看 demo 流畅度）
- 单订单 HK$300（高端进口食材有溢价空间）

**风险（不要藏）**
- 朋友推荐转化可能比预期低（首批 100 β 是关键样本）
- 供应商 B2C 物流是新挑战（建议 1 个月 MVP 验证）
- β 转付费比例 5-10% 是行业中位（真实可能 2-12%）
