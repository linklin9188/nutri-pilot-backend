# 老板 daily 真测 checklist

**目的**：老板每天花 10 分钟用一遍 nothinkeats.com 核心路径，发现 bug 立即派工单修，**内测前 polish 产品**。
**版本**：v1（CEO 起草于 2026-05-24，老板有想加 / 改 / 删告诉 CEO）
**预计耗时**：8-10 分钟

---

## 使用方法

1. **必须用无痕窗口打开** https://nothinkeats.com
   - Chrome：`Cmd+Shift+N`
   - Safari：`Cmd+Shift+N`
   - 原因：算法版本号改了，老缓存会显示老菜单
2. 按下面顺序跑，每步打 ✅ / ❌ + 写一句话观察
3. **发现 ❌** → 截图或文字告诉 CEO → CEO 立即派工单修

---

## 1️⃣ 首页（1 分钟）

- [ ] `/home` 打开正常，不白屏 / 不报错
- [ ] 工作日：看到本周菜单
- [ ] 周末：看到 hero "周末好，出门换换口味吧" + 5 餐厅推荐
- [ ] 顶部 hero 文案 + 副标符合时段

---

## 2️⃣ 本周菜单（3 分钟，**重点**）

- [ ] `/weekly` 打开正常
- [ ] 周一到周五 5 天都有菜单，不空
- [ ] **早餐 protein 5 种蛋不重复**（茶叶蛋 / 白煮蛋 / 鸡蛋羹 / 煎鸡蛋 / 葱花炒鸡蛋）
- [ ] 每天早餐有 4 大营养类：碳水 + 蛋白 + 蔬菜 + 水果
- [ ] 周末**不显示**"下周菜单" nav 入口
- [ ] 点任一菜卡，跳菜详情正常，不报错

---

## 3️⃣ 采购清单（2 分钟）

- [ ] `/weekly` 点 **"一键生成本周购物清单"** 按钮
- [ ] 应跳 `/verify-ingredients`
- [ ] 食材清单列出来，不空，不重复
- [ ] **（第 4 步供货商上线后）** 命中供货商食材应显示：
  - "由 X 直供" 标签
  - "还剩 N 件" 库存数
  - "一键下单" 按钮
  - 点按钮应跳供货商落地页 / WhatsApp

---

## 4️⃣ Settings 个人设置（1.5 分钟）

- [ ] `/settings` 看到 "🎯 我的口味偏好" + "💎 会员中心" **两个单入口**（不分散到各个 tab）
- [ ] 点 "我的口味偏好" → 多维度 chip + 200 字 textarea，能保存
- [ ] 点 "会员中心" → 看到权限列表 + **"目前全部免费"** 标语
- [ ] **整页都看不到 'Ika' 字样**（菲佣占位应为"菲佣"或你 nickname）

---

## 5️⃣ 菲佣端（1 分钟）

- [ ] `/helper-home` 应**只问**：[菲律宾] [印度尼西亚] 二选
- [ ] 不问辣度 / 口味 / 健康目标（spec 简化）
- [ ] 切到 helper 角色，**整端看不到** "免费试用" / "trial" / "Free trial" 任何字眼

---

## 6️⃣ 登录页（1 分钟）

- [ ] `/login` 默认**简体中文**
- [ ] 切 [菲佣] 角色：
  - 隐藏 FB / IG / Google 登录按钮（微信审核要求）
  - 隐藏 "（免费试用 30 天）" 字样
- [ ] 切 [雇主] 角色：
  - 微信登录按钮下小字显示 "（免费试用 30 天）"

---

## 7️⃣ 微信登录（如果手机方便测）（1 分钟）

- [ ] 手机扫码登录微信
- [ ] 登录后看到**老板你自己的真昵称**（不是 'Ika' / 不是默认值）
- [ ] `/home` 头像应是老板你的真微信头像

---

## 发现 bug 的快速通道

直接告诉 CEO：

```
第 X 步 ❌
现象：(截图 / 文字描述)
期望：(你觉得应该咋样)
```

CEO 立即派工单修，**当天 ship**（除非超出 95% 自决范围，那种情况 CEO 会请示）。
