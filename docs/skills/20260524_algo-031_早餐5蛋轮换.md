# 早餐 5 蛋轮换（TICKET-031）

**任务**：TICKET-031 P0 — 早餐每天都是茶叶蛋，修成 5 蛋 5 工作日轮换
**完工时间**：2026-05-24 HKT

## 1. 解决了什么问题

用户老板真测发现：周一到周五早餐 protein 永远是「茶叶蛋」，其他 4 种（白煮蛋 / 鸡蛋羹 / 煎鸡蛋 / 葱花炒鸡蛋）永远不出。根因在 `breakfastCombos.ts` 13/14 个 combo 硬编码 `side[0]='茶叶蛋'`，是算法 bug 不是数据问题。

之前 TICKET-005 加过 shuffleSeed 做 keywords Fisher-Yates 打散，但因为 `'茶叶蛋'` 是 keywords 数组里唯一的蛋类 keyword，shuffle 之后仍然永远命中它 — shuffle 只能打乱顺序，不能扩 keyword 池。

## 2. 用了什么关键方法

- 加 sentinel placeholder `EGG_PLACEHOLDER = '__EGG_DAY_ROTATION__'` 替换硬编码菜名，避免误命中真实 dish (双下划线包裹 + 全大写 + 大概率不在任何真菜名里)
- pool 数组 `BREAKFAST_PROTEIN_EGG_POOL` 5 蛋按工作日次序
- `resolveSlot` 加 `dayIndex` 参数，遇 placeholder 按 `dayIndex % 5` 轮换索引 (起点 dayIndex，依次 +1 +2 +3 +4 mod 5)，5 蛋都 miss 才 fallback 到 combo 后续 keyword
- 港式 hk-tea-restaurant combo 保留 `'煎蛋'/'炒蛋'/'蛋饼'` 原 3 蛋特化，追加 placeholder 接尾保证语境兼容 (港式 3 蛋优先命中, miss 才 fallback 5 蛋池)
- bump `ALGO_VERSION` v62 → v63 让全部用户本地缓存失效
