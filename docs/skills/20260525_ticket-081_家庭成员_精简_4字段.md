# TICKET TELEPOT-20260525-081 — 家庭成员 UI 精简 4 字段

## 问题

TICKET-072 (commit 9e80e92) 给 Settings 家庭成员抽屉加了 spec §1.2 的完整
12 字段编辑 UI: name / relation (7 子角色) / gender / age_years / height_cm /
weight_kg / dietary_goal (6 选) / allergens / chronic_diseases / dietary_mode
(5 选) / tcm_constitution (8 选) / pregnancy_status (6 选) + lifeStage +
needs 两层兼容编辑。老板真测 #21 直接砍："年龄、身高、体重、关系，这些信息对
我们推荐菜单有什么用呢? 根本不需要获取。"

CEO 实查算法 (useWeeklyMenu / useSupabaseMenu / recommendVector) 真用 vs 没用:

- **真用 4 个**: `name` (UI 显示) / `relation` 二分 (adult|child, 早餐/儿童 slot) /
  `avoid_tags` (hardFilter 删菜 + recommendVector 衰减) / `dietary_mode`
  (素食/全素 → 物理删肉)
- **完全没用 9 个**: age_years / height_cm / weight_kg / gender / dietary_goal /
  chronic_diseases / tcm_constitution / pregnancy_status / relation 的
  spouse/father/mother/etc 具体子角色

dead UI 字段是 onboarding 阻力 (用户加一个孩子要填 12 项，9 项白填) 又是 false
sense of personalization (用户以为输完会更准，其实算法根本不读)。

## 方法

**UI 精简到 4 输入**:

1. 名字 (text input)
2. 类型 (大人 / 孩子 二选一) — `relation: 'adult' | 'child'` + 派生
   `lifeStage` 同步 (adult→普通成人 / child→儿童) 保 `familyPrefs.ts`
   兼容
3. 过敏 / 不吃啥 (9 chip 多选: 海鲜/坚果/乳制品/麸质/鸡蛋/大豆/花生/牛肉/猪肉) —
   id 必须用算法 `ALLERGEN_TO_INGREDIENTS` 的英文 key, 同步回写中文标签到
   `m.needs` 数组兼容 `familyPrefs.convertNutriMembers`
4. 饮食习惯 (都吃 / 素食 / 全素 三选一)

**DB schema 不动**: `family_members` 9 字段保留 nullable, `uiToDB` 写 null
DB 接受。`lib/familyMembers.ts` CRUD 接口不动。算法侧
(recommendVector / useWeeklyMenu) 已经只读真用字段，自动兼容。

**关键反向 sync**: 打开抽屉时把老数据 `m.needs` 里的中文忌口 ("不吃海鲜" 等)
反向 sync 到 `m.allergens` 英文数组让 chip 高亮，避免老用户感觉数据丢了。

**卡片显示**: 只显 emoji (大人 🧑 / 孩子 🧒) + 名字 + 大人/孩子 chip +
过敏摘要前 2。删 lifeStage chip / dietary_goal label / "点击完善 12 字段档案"
文案 (改 "点击编辑")。

**三语 t4 全覆盖** (en/zh/tl/id)。主色橙 `#FF5A1F` 保持。

## 标准

**今后所有用户输入字段必须先验证"算法/UI 真用" 才上 UI**。schema 先于
use case 是 dead UI 的根因 (TICKET-072 spec §1.2 拍 12 字段是 schema-first,
没问"算法读不读"就 ship)。下次类似 spec 必须先跑一遍:

1. grep 算法 (useWeeklyMenu / useSupabaseMenu / recommendVector /
   familyPrefs) 真读哪些字段
2. 真读 = 真用 → 上 UI; 不读 = dead → 砍或 nullable 兜底
3. spec 写 "12 字段" 不代表 12 字段都上 UI; UI 只 expose user-actionable
   subset
