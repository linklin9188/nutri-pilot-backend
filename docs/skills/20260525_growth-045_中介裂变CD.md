## 大白话 1 段 — 这次到底做了啥

老板拍板的中介裂变是 A+C+D 三件套。A 已 ship（注册时填推荐码 → 写
`user_profiles.referred_by_agency_id`）。本棒只做 C+D 两件 **纯 UI 显示** 的活：
被中介推荐过来的用户进 Settings 时，头像挂个"💎 VIP"金色小角标、名字下方
多一行"由 XX 家政推荐"、原本的"📩 联系客服"按钮自动变成"📞 联系专属客服"
并把 mailto 邮箱从 `support@nothinkeats.com` 换到 `vip@nothinkeats.com`。
没被推荐过来的普通用户屏幕完全不变 —— C+D 走的就是同一个
`agency` state 的 truthy 判断，没有就当 0 副作用。

## 大白话 2 段 — 为什么这么做（PDPO + 改最少）

**PDPO 合规优先**：仅展示 `agency.name`，**不**展示 `contact_whatsapp` /
`contact_email`。中介注册时填的联系方式属于中介的私人 PII，不该被路人用户
看见 — 防止竞品爬完整中介通讯录。所以 fetch agency 时只 select `id, name`
两个字段，bundle 里翻不到中介电话。

**屏蔽 pending 中介**：migration 087 RLS policy 已经卡死 `status = 'active'`
才能被 anon SELECT。意味着 fetchReferringAgency 拿到的 agency 要么是
active 真 ship 的、要么 `null`（pending / paused / 删了都拿不到）。
前端不用再判一次 status，Supabase 帮我们做了。

**改动面积最小**：

- 加 1 个 useEffect（先读 `user_profiles.referred_by_agency_id`，有值再读
  `agencies` 拿 name）+ 1 个 state `agency`。
- 头像 label 的 VIP chip：在 `</label>` 之前塞 1 个 absolute
  `-top-1 -right-1` 黄底 chip，跟原有的相机角标 `-right-0.5 -bottom-0.5`
  错开不打架。原 label 已经是 `relative`，无需再加。
- 名字下方"由 X 推荐"：紧接在 role chip 那行 `</div>` 之后再加 1 个
  `<p className="text-[11px] text-gray-500 mt-1 truncate">`。
- 联系客服按钮 + sheet：把硬编码的 `📩 联系客服` 文案 / `SUPPORT_EMAIL`
  全部换成三元判断 `agency ? VIP_xxx : SUPPORT_xxx`。`VIP_EMAIL` 沿用
  TICKET-066 §B 的"JS 拼接防爬虫"写法 `["vip", "nothinkeats.com"].join("@")`。

## 大白话 3 段 — 下棒踩坑提醒

1. **`useEffect` 依赖空数组 `[]`** — 这是有意的。`getUserId()` 来自
   localStorage，登录后整个 session 不会变；如果哪天加了切换账号入口，记得
   把这里改成依赖 userId 或 onAuthStateChange。

2. **`vip@nothinkeats.com` 邮箱本身需要后台另开** — UI 这边只是塞 mailto
   链接，真正的邮箱路由（Cloudflare Email Routing → Gmail filter）需要 Backend
   或运维去开。如果用户点了发不出去 / 弹邮件配置缺失，那是 Email Routing
   没设，不是 UI bug。

3. **VIP chip 不要靠 `proReason === 'paid'` 判** — 这跟 Stripe 订阅 Pro 是
   两件事。中介推荐的"VIP"是终身免费 + 专属客服的服务包，跟 Stripe Pro
   `proReason === 'paid'` 没关联，纯粹由 `referred_by_agency_id` 判。后续若
   要做"VIP 同时附赠 Pro 权限"，要去后端 subscription 层挂逻辑、别在 UI
   层硬塞 chip。

4. **C 文案"由 X 推荐"必须永远显示 agency.name**，不能跟 `myDisplayName`
   合并到一行 — 老板要的是品牌挂名曝光，别为了视觉精简把 agency name 藏
   到 tooltip / 折叠卡里。Settings 头像区是中介的"门面墙"。

5. **`agencies` 表 select 只能挑 `id, name`** — 任何场合都不要 SELECT *
   或加 `contact_whatsapp` / `contact_email`。如果未来要做"用户可以联系
   推荐我的中介"，必须老板 + PDPO 再过一遍同意书路径，不能 UI 默认显示。
